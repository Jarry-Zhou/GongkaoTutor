# 国考行测默认数据来源

来源：[ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)，固定提交 `278984401124db40da5163a31275b8deb9c282f4`。

`source.json` 只保存公开文件路径、长度和Git blob校验值，不包含题面、答案、解析或图片。首次安装从固定提交下载2016—2026国考行测整理数据，之后离线使用。保留来源的整理/网友回忆版标记，未逐题官方核验，不承诺全部官方卷型完整。

本版本包含27个卷型索引、3564条题目记录，其中按文字、选项、材料与题面图片内容合并为2711个指纹；3780张来源配图。跨卷重复保留，指纹数不等同于经过人工判定的独立真题数。

此源不含完整申论材料。上游未提供独立题库转载许可，题目与解析内容不属于本项目MIT授权的代码；不在本项目仓库和发布包中重分发。请遵守原来源与权利人的使用要求。
