# 使用手册

## 导入资料与题库

从“我的题库”“知识资料”或“导入任务”进入批量导入。单文件最多500 MB，每批最多100个；同一批可传两类文件，要逐个指定“知识资料”或“题库”。资料进入检索库，题库预览核对后入库。

支持JSON/CSV/TSV/XLSX，以及TXT/Markdown、DOCX、PDF和常见图片。扫描资料默认逐页OCR。服务继续运行时可关闭浏览器等待解析；电脑休眠、关机或停止服务会中断处理。

任务可重试或可恢复删除。资料支持全文阅读与搜索，局部页可补识别。图推、图表应核对单题裁图和答案，不把整页多题当作一道题。

## 练习与组卷

模块练习按模块、知识点、难度、错题或未见题筛选；模拟组卷按模块配额、分值和时长抽题。答案自动保存，可补充理由、疑惑、草稿图和实际思路。

交卷后保存原作答与成绩，主观题保持待评阅，模型结果不覆盖原成绩。至少3次满足独立、未见题、无提示、全部计分条件的限时模考后，才给近期表现区间；它未经过真实考试校准。

## 综合AI与短训练

在学习诊断、能力与训练或结果页打开“查看/更新AI分析”。先核对新增作答、修订和短训练数量，再确认调用API。

旧结论持久保留，只发送必要摘要及本批新增、修订证据；无新证据时复用。有批次与图像上限，剩余记录留待下一批确认，失败不覆盖旧结论或推进游标。

AI给出具体表现、原因假设和分步练习。核对原句、材料引文后，练对应步骤，再换未见题复测。短训练计时是页面停留记录，走神、离开或查资料时应暂停。

## 申论

按归纳概括、综合分析、对策、公文和大作文练习。核对题型、实际满分和字数要求。小题对照材料采点与表达组织，大作文、材料不全或未知分值只给定性建议。

仅上传手写草稿时，先确认识读，再对照原图修正并确认文字，然后用于批改。

七维画像包括层次划分、主旨凝练、业务熟悉度、材料要点提取、关系与论证、表达规范、作答效率。每项保留原句、材料依据、变化和验证任务。业务不熟需过程证据，具体耗时环节需分步记录。

同题修改只计一道题，短训练单列。材料、条件或思路变化后，相关依据待校验，历史报告保留。

## 计算训练

单项速练每题换数，可选5/10/20/30题；同组联练用一组A、B和增长率推算多个指标。题型多选，难度分基础、常规与进阶，进阶含负增长。

绝对误差≤3均达标，包含边界。数量按亿元，百分数按百分点；参考值先保留两位小数。直接填`21.92`或`21.92%`表示21.92%，空白不当作0。接近零且方向不同的结果按范围判定，并提示核对方向。

提交后展开公式和代入过程。单项回车提交后再按回车继续；同组回车跳下一项，最后一项回车提交整组。提示使用、暂停、草稿和历史独立保存，未达标题型可换数再练。

计算训练本地运行，不调用模型，不混入模考成绩。反馈阅读、手动暂停、切页和后台均停计，失联时最多额外记30秒。
