# 0.11 国考真题替换

用户明确要求本机题库和GitHub默认题库都替换为真题，原作答与历史成绩保留。来源固定为ERRRC/xingcezhenti提交278984401124db40da5163a31275b8deb9c282f4，仅取2016—2026国考行测，不混入省考。上游的网友回忆版、整理版身份保留，不把来源答案称为经过官方逐题核验。

当前来源未提供独立题库转载许可。GitHub分发解析、安装代码与公开路径/校验清单，首次安装从固定来源下载，之后离线练习；不把题面和解析内容改挂为本项目MIT。原39道默认仿题退出默认入口。此源不含完整申论材料，原申论题与其他旧题一并保留于可恢复旧题库，不能将只有题干或答案的申论语料冒充完整真题。

下载逐文件校验Git blob SHA，保留HTML文字、图形、表格及公式图。题面、选项、共用材料和来源解析分别解析，不能把答案勾选或解析图混进题面。以试卷和qid定位题目，保留模块内题号、年份、卷型、题目出处。资料分析按材料组关联；相同题跨卷重复计数在审计报告中单列，不冒充不同题数量。

网页使用受限结构化节点渲染文字、图片和表格，不注入上游HTML。图片来自本地SHA-256寻址资源。AI仅接收本题和本材料的图像拼图；解析图另列，不进入作答题面。批次图像数按实际资料/题目角色计数。

bank_catalog保存当前隐藏旧题集合、安装事件和恢复信息，原questions、sessions、attempts等行不覆盖。常规题库、练习和库存仅显示当前集合；原记录仍可查阅旧题及图片。恢复旧库是本地事务，不删除新库文件。下载、校验或解析失败不改变题库。

验收：题数与源声明一致、答案选项和勾选一致、配图完整、组材料准确、答案不泄漏、持久/恢复/重入幂等、旧数据逐行保留、无付费调用。完整副本验收后部署本机，并同步GitHub代码及新版本发布。

## 下载、替换与恢复

新安装执行“首次安装.cmd”自动下载，已有题库不自动覆盖。页面入口为“我的题库→国考真题库”，查看状态后确认替换；恢复使用同处“恢复旧题库”。也可在停止服务后运行：

```powershell
.\.venv\Scripts\python.exe scripts/install_national_bank.py --replace
.\.venv\Scripts\python.exe scripts/install_national_bank.py --restore
```

完整备份需复制整个data目录，除SQLite外包含national-bank下的配图、校验缓存与准备结果。下载中断不切换题库，重新下载复用已经校验的文件。旧题行和新题行都保留，恢复只切换可见目录。

本版本共3564条卷内题目记录、27个卷型索引、2711个题面指纹、3780张来源配图。指纹包含文字、选项、材料及题面图片内容，仅作机械去重，不声称人工核定独立题量。

## 版本验收

逐一核验158份模块文件和3780张来源图片的长度与Git blob SHA，3564条记录均通过结构、答案和选项一致性检查，无来源图片缺失警告。合成测试覆盖受限渲染、图形去重、答案隔离、分组顺序、下载校验、事务归档、恢复和幂等安装。浏览器验证图推选答、核对、交卷、复盘，资料完整材料与独立答题区，以及恢复旧库与复用缓存重新启用。结构检查不代表逐题内容或解析正确性已人工核验。
